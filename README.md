# 📘 Complete JavaScript Learning - Saroj Dhital

A structured collection of **JavaScript concept notes and practice files**, built step-by-step while learning.

Each file is a self-contained reference covering one concept area, with beginner-friendly explanations, meant to be revisited anytime as a quick refresher.

---

## 🛠 Tech Used

- JavaScript (ES6+)
- Node.js (to run files locally)

---

## 📂 Repository Structure

Files are numbered in the order concepts were learned.

```
Complete_Javascript_Learning/
├── 01-javascript-functions-reference.js
├── 02-...
└── README.md
```
---

## 📗 How to Use

```bash
git clone https://github.com/Joras-Latihd/Complete_Javascript_Learning.git
cd Complete_Javascript_Learning
node 01-javascript-functions-reference.js
```
